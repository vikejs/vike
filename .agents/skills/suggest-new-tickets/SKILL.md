Suggest new tickets. Nobody will answer you: never ask, decide yourself. Read the project, its README, its documentation and its code, and every open ticket. Think of the work the project should do next: bugs, missing pieces, cleanups worth their cost, features. Skip anything an open ticket already covers. Write each suggestion as a new ticket in the project's ticket format. You change nothing else. Your last message lists the tickets you wrote, one line each. If nothing is worth suggesting, say so and stop. If this project has no ticketing system, show an error to the user and stop.
