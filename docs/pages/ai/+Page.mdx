Vike has built-in integration with AI agents.


## `vike.dev/llms.txt`

The Vike documentation is indexed by [vike.dev/llms.txt](https://vike.dev/llms.txt) — a compact documentation index for AI agents.

> Most AI models are familiar and proficient with most of Vike's features. That said, agents often use advanced Vike features in an unidiomatic way.
>
> Therefore, if your AI agent doesn't automatically load it (see the skill below), we recommend instructing your agent to load [vike.dev/llms.txt](https://vike.dev/llms.txt) in its context whenever it uses uncommon Vike APIs.


## Skill

Vike automatically adds the following [agent skill](https://agentskills.io) making AI agents (Claude Code, Codex, Cursor, Gemini CLI, ...) automatically aware of the Vike documentation.

```md
// .agents/skills/vike/SKILL.md

---
name: "vike"
description: "Vike documentation — consider reading it, e.g. when using uncommon Vike APIs or when stuck on a Vike problem"
---

See https://vike.dev/llms.txt
```

Upon running the development server, Vike adds the skill file to every existing skills directory (`**/skills/*/SKILL.md`) of your app's Git repository — e.g. `.claude/skills/` (Claude Code) and `.agents/skills/` (Codex, Gemini CLI, Cursor, and many others) — and automatically Git-commits it. If a skill file exists but is outdated, Vike updates it (and Git-commits the change).

It's skipped if:
- Your app doesn't contain any skills directory. (Unless you use `+ai.skill` to set the list of directories.)
- The setting `+ai.skill` is `false`.
- Your app isn't inside a Git repository.
- You're in a CI environment.

> If you `.gitignore` a skill file (e.g. by adding `.claude/` to your `.gitignore`), then Vike still creates the file but doesn't Git-commit it.

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  ai: {
    // Never add the skill file
    skill: false,
    // Add the skill file to exactly these directories (creating them if needed)
    skill: ['.agents/skills', '.claude/skills']
  }
} satisfies Config
```
