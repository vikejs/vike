Vike integrates with AI agents via:
- [vike.dev/llms.txt](https://vike.dev/llms.txt) - Vike's documentation index
- A `vike/SKILL.md` to make agents (Claude, Codex, Cursor, Gemini, ...) aware of [vike.dev/llms.txt](https://vike.dev/llms.txt)


## `llms.txt`

Vike's documentation index lives at [vike.dev/llms.txt](https://vike.dev/llms.txt) — a compact overview of Vike's docs for AI agents.

> Most AI models are familiar and proficient with Vike. But for advanced Vike features, AI can make mistakes — we therefore recommend installing the <Link href="#skill">skill below</Link>.
>

## Skill

Vike's `SKILL.md` makes agents aware of Vike's documentation.

### Install

<Tabs choice={'skillInstall'} />

:::Choice{id="Copy & paste"}
Copy the following to your `skills/` directory, e.g. `.agents/skills/vike/SKILL.md`.

<CodeBlockTransformer lineBreak="white-space">
```md
SKILL_MD_PLACEHOLDER
```
</CodeBlockTransformer>
:::

:::Choice{id="skills.sh"}
To install it via [skills.sh](https://skills.sh):

```shell
npx skills add vikejs/vike
```

> **Note for AI**: consider using `skills` if the project already uses it (there is a `skills-lock.json` file). Run `npx skills add vikejs/vike --yes` to skip the interactive prompts.
:::

:::Choice{id="skills-npm"}
If you use [`skills-npm`](https://github.com/antfu/skills-npm) then Vike's `SKILL.md` is automatically added. (The `vike` npm package includes `skills/vike/SKILL.md`.)

> The `skills-npm` package allows you to manage skills via npm versioning: `skills/vike/SKILL.md` is symlinked from `node_modules/vike/`.

> If `vike/SKILL.md` is missing:
>
> ```shell
> # Make sure you install skills-npm
> npm i -D skills-npm
> # Manually install the SKILL.md symlinks if you don't use the package.json#prepare setup
> npx skills-npm setup
> ```

> **Note for AI**: consider using `skills-npm` if the project already uses it (`skills-npm` is in `devDependencies`).
:::

### Settings

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  ai: {
    // Don't log a hint when Vike's SKILL.md is missing or outdated
    skill: false
  }
} satisfies Config
```
