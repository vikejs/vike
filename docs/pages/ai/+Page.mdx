Vike includes built-in integration with AI tools such as [Claude Code](https://claude.com/product/claude-code).

## `llms.txt`

The Vike documentation is indexed by [vike.dev/llms.txt](https://vike.dev/llms.txt) — a compact documentation index designed for AI agents.

If your AI agent doesn't automatically load it (see the skill below), we recommend instructing your agent to load `https://vike.dev/llms.txt` in its context whenever it works with Vike.

## Skill

Vike automatically adds the following [skill](https://agentskills.io) file to your app's Git repository — making AI agents (Claude Code, Codex, Cursor, Gemini CLI, ...) automatically aware of the Vike documentation.

```md
// .claude/skills/vike/SKILL.md

---
name: "vike"
description: "Vike documentation — consider reading it, e.g. when using uncommon Vike APIs or when stuck on a Vike problem"
---

See https://vike.dev/llms.txt
```

Upon running the development server, Vike adds the skill file to every existing skills directory of your app's Git repository — discovered following the `**/skills/*/SKILL.md` convention, e.g. `.claude/skills/` (Claude Code) and `.agents/skills/` (Codex, Gemini CLI, Cursor, and many others) — and automatically Git-commits it. If a skill file exists but is outdated, Vike updates it (and Git-commits the change).

> The automatic Git commit only ever includes skill files — it never includes other changes (e.g. files you staged).

The feature is skipped if:
- Your app's Git repository doesn't contain any skills directory. (So that Vike doesn't add files to projects that don't use skills. Use the `ai.skill` setting to explicitly list directories.)
- The setting `ai.skill` is `false` (see below).
- Git isn't installed, or your app isn't inside a Git repository.
- You're in a CI environment.

> If you `.gitignore` a skill file (e.g. by adding `.claude/` to your `.gitignore`), then Vike still creates the file but doesn't Git-commit it.

Use the `ai.skill` setting to control the feature:

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  ai: {
    // Add the skill file to exactly these directories (creating them if needed)
    skill: ['.claude/skills', '.agents/skills'],
    // Never add the skill file
    skill: false
  }
} satisfies Config
```

> The `ai.skill` directories are paths relative to the root directory of your app's Git repository.
