Vike integrates with AI agents via:
- Vike's documentation index at [vike.dev/llms.txt](https://vike.dev/llms.txt)
- A [`vike/SKILL.md`](https://agentskills.io) to make agents (Claude, Codex, Cursor, Gemini, ...) aware of [vike.dev/llms.txt](https://vike.dev/llms.txt)


## `llms.txt`

Vike's documentation index lives at [vike.dev/llms.txt](https://vike.dev/llms.txt) — a compact overview of Vike's docs for AI agents.

> Most AI models are familiar and proficient with Vike. But for advanced Vike features AI can make mistakes and, therefore, we recommend installing the <Link href="#skill">skill below</Link>.
>

## Skill

Vike's skill `vike/SKILL.md` makes AI agents (Claude Code, Codex, Cursor, Gemini CLI, ...) aware of Vike's documentation.

> Vike checks whether your app has the skill: if it's missing or outdated, Vike logs a hint telling you how to <Link href="#install">install</Link> it. Vike never modifies your repository.

### Install

<Tabs choice={'skillInstall'} />

:::Choice{id="Copy & paste"}
Add the following `vike/SKILL.md` to your `skills/` directory (e.g. `.agents/skills/vike/SKILL.md` or `.claude/skills/vike/SKILL.md`), and commit it.

<CodeBlockTransformer lineBreak="white-space">
```md
SKILL_MD_PLACEHOLDER
```
</CodeBlockTransformer>
:::

:::Choice{id="skills.sh"}
Install it with [skills.sh](https://skills.sh), which adds it to the skills directories of the AI agents you use:

```shell
npx skills add vikejs/vike
```

> To update the skill, run `npx skills update vike`.
:::

:::Choice{#skills-npm}
Install [`skills-npm`](https://github.com/antfu/skills-npm), which symlinks the skills shipped by your npm dependencies (the `vike` npm package ships `vike/SKILL.md`):

```shell
npm i -D skills-npm
npx skills-npm setup
```

> The skill is symlinked from `node_modules/vike/skills/vike/`: it's always in sync with your installed Vike version, and there is nothing to commit.
:::

> **Note for AI agents**: if the project already uses skills.sh (there is a `skills-lock.json` file) or `skills-npm` (it's in `devDependencies`), use it; otherwise copy & paste the skill.

### Settings

To disable the check:

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  ai: {
    // Don't check whether Vike's skill is installed
    skill: false
  }
} satisfies Config
```
