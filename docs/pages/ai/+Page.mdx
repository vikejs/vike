Vike integrates with AI agents via:
- Vike's documentation index at [vike.dev/llms.txt](https://vike.dev/llms.txt)
- A [SKILL.md](https://agentskills.io) to makes AI agents (Claude, Codex, Cursor, Gemini, ...) consult [vike.dev/llms.txt](https://vike.dev/llms.txt) when needed


## `llms.txt`

Vike's documentation index lives at [vike.dev/llms.txt](https://vike.dev/llms.txt) — a compact overview of Vike's docs for AI agents.

> Most AI models are familiar and proficient with Vike. But for advanced Vike features AI can make mistakes.
>
> Therefore, if your AI agent doesn't automatically load it (see the skill below), we recommend instructing your agent to read [vike.dev/llms.txt](https://vike.dev/llms.txt) whenever it uses Vike in an uncommon way.


## Skill

Vike automatically adds the following `skills/vike/SKILL.md` to make AI agents (Claude Code, Codex, Cursor, Gemini CLI, ...) automatically aware of Vike's documentation.

```md
---
name: "vike"
description: "Vike documentation index — a compact overview of Vike's docs. Consider consulting it, e.g. when using uncommon Vike APIs or when stuck on a Vike problem."
---

See https://vike.dev/llms.txt
```

> Upon running the development server, Vike adds `vike/SKILL.md` to every existing agent skills directory (`**/skills/*/SKILL.md`) and automatically Git-commits it. If the skill file is outdated, Vike updates it (and Git-commits the change).

Vike skips adding `vike/SKILL.md` if:
- The setting `+ai.skill` is `false`.
- Your app doesn't contain any skills directory. (Unless you set `+ai.skill` to a list of directories.)
- Your app isn't inside a Git repository.
- You're in a CI environment.

> If you `.gitignore` a skill file (e.g. by adding `.agents/skills/` to your `.gitignore`), then Vike still creates the file but doesn't Git-commit it.

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  ai: {
    // Never add vike/SKILL.md
    skill: false,
    // Add vike/SKILL.md to exactly these directories
    skill: ['.agents/skills', '.claude/skills']
  }
} satisfies Config
```
