Vike integration with AI agents.


## `llms.txt`

The Vike documentation is indexed by [vike.dev/llms.txt](https://vike.dev/llms.txt) — a compact documentation index for AI agents.

> Most AI models are familiar and proficient with Vike. But for advanced Vike features agents can make mistakes.
>
> Therefore, if your AI agent doesn't automatically load it (see the skill below), we recommend instructing your agent to read [vike.dev/llms.txt](https://vike.dev/llms.txt) whenever it uses Vike in an uncommon way.


## Skill

Vike automatically adds the following `skills/vike/SKILL.md` to make AI agents (Claude Code, Codex, Cursor, Gemini CLI, ...) automatically aware of Vike's documentation.

```md
---
name: "vike"
description: "Vike documentation — consider reading it, e.g. when using uncommon Vike APIs or when stuck on a Vike problem"
---

See https://vike.dev/llms.txt
```

> Upon running the development server, Vike adds the skill file to every existing skills directory (`**/skills/*/SKILL.md`).

Vike skips adding `skills/vike/SKILL.md` if:
- The setting `+ai.skill` is `false`.
- Your app doesn't contain any skills directory. (Unless you set `+ai.skill` to a list of directories.)
- Your app isn't inside a Git repository.
- You're in a CI environment.

> If you `.gitignore` a skill file (e.g. by adding `.claude/` to your `.gitignore`), then Vike still creates the file but doesn't Git-commit it.

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  ai: {
    // Never add vike/SKILL.md
    skill: false,
    // Add vike/SKILL.md to exactly these directories
    skill: ['.agents/skills', '.claude/skills']
  }
} satisfies Config
```
