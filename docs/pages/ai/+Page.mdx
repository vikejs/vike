Vike integrates with AI agents via:
- Vike's documentation index at [vike.dev/llms.txt](https://vike.dev/llms.txt)
- A `vike/SKILL.md` to make agents (Claude, Codex, Cursor, Gemini, ...) aware of [vike.dev/llms.txt](https://vike.dev/llms.txt)


## `llms.txt`

Vike's documentation index lives at [vike.dev/llms.txt](https://vike.dev/llms.txt) — a compact overview of Vike's docs for AI agents.

> Most AI models are familiar and proficient with Vike. But for advanced Vike features, AI can make mistakes — we therefore recommend installing the <Link href="#skill">skill below</Link>.
>

## Skill

Vike's `SKILL.md` makes agents aware of Vike's documentation.

### Install

<Tabs choice={'skillInstall'} />

:::Choice{id="Copy & paste"}
Copy the following to your `skills/` directory, e.g. `.agents/skills/vike/SKILL.md`.

<CodeBlockTransformer lineBreak="white-space">
```md
SKILL_MD_PLACEHOLDER
```
</CodeBlockTransformer>

> **Note for AI agents**: use this method unless the project already uses skills.sh or skills-npm (see the other tabs). Save the file in the project's existing skills directory if there is one, otherwise in the skills directory of the AI agent(s) used by the project (e.g. `.claude/skills/vike/SKILL.md` for Claude Code, `.agents/skills/vike/SKILL.md` for Codex, Cursor, Gemini CLI, and GitHub Copilot).
:::

:::Choice{id="skills.sh"}
Install it with [skills.sh](https://skills.sh), which adds it to the skills directories of the AI agents you use:

```shell
npx skills add vikejs/vike
```

> To update the skill, run `npx skills update vike`.

> **Note for AI agents**: use this method if the project already uses skills.sh (there is a `skills-lock.json` file). Run `npx skills add vikejs/vike --yes` to skip the interactive prompts, then commit the added files.
:::

:::Choice{#skills-npm}
Install [`skills-npm`](https://github.com/antfu/skills-npm), which symlinks the skills shipped by your npm dependencies (the `vike` npm package ships `vike/SKILL.md`):

```shell
npm i -D skills-npm
npx skills-npm setup
```

> The skill is symlinked from `node_modules/vike/skills/vike/`: it's always in sync with your installed Vike version, and there is nothing to commit.

> **Note for AI agents**: use this method if the project already uses skills-npm (`skills-npm` is in `devDependencies`). Run `npx skills-npm` to symlink the skill (it also runs automatically upon `npm install`); there is nothing to commit.
:::

### Settings

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  ai: {
    // Don't log a hint when Vike's skill is missing or outdated
    skill: false
  }
} satisfies Config
```
