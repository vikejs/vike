The `rootAttributes` setting adds attributes to the root element, i.e. the element in which the <UiFrameworkExtension /> renders your pages.

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  // <div id="root" role="none">
  rootAttributes: { role: 'none' }
} satisfies Config
```

> The root element is `<div id="root">` with `vike-react` and `vike-solid`, and `<div id="app">` with `vike-vue`.

> **Accessibility**: React attaches its event listeners to the root element, which leads accessibility tools (such as the Firefox Accessibility Inspector and some screen readers) to consider the root element as clickable, see [facebook/react#20895](https://github.com/facebook/react/issues/20895). Setting `role="none"` fixes that.
