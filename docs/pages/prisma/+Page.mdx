You can use Prisma ORM wherever your code runs on the server, for example in <Link href="/data">`+data` hooks</Link> and <Link href="/api-routes">API routes</Link>. It doesn't need any Vike-specific integration.


## Guide

Prisma's documentation has a guide for Vike:

- [Prisma Docs > Vike](https://www.prisma.io/docs/guides/frameworks/vike?utm_source=vike&utm_medium=docs&utm_campaign=ecosystem&utm_content=prisma)

It adds Prisma ORM to a scaffolded Vike app, stores the app's data in a [Prisma Postgres](https://www.prisma.io/postgres?utm_source=vike&utm_medium=docs&utm_campaign=ecosystem&utm_content=prisma) database, and deploys the app to [Prisma Compute](https://www.prisma.io/compute?utm_source=vike&utm_medium=docs&utm_campaign=ecosystem&utm_content=prisma).

> The guide uses Prisma ORM 8, whereas <Link href="/new">vike.dev/new</Link> currently scaffolds Prisma ORM 7.

> Deploying to Prisma Compute doesn't require a Vite adapter: it runs the production server that `$ vike build` generates when you set <Link href="/server">`+server`</Link>.
