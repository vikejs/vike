`throw abort()` aborts a client-side navigation: the user stays on the current page.

For example, to ask for confirmation before leaving a page with unsaved changes:

```ts
// /pages/editor/+onPageTransitionStart.ts
// Environment: client

import { abort } from 'vike/abort'

export function onPageTransitionStart() {
  if (hasUnsavedChanges() && !window.confirm('Leave this page? Your changes will be lost.')) {
    throw abort()
  }
}
```

> The browser's [`beforeunload` dialog](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeunload_event) isn't shown upon client-side navigation.

You can use `throw abort()` only in <Link href="/onPageTransitionStart">`onPageTransitionStart()`</Link>: it's the first hook Vike calls upon client-side navigation, and it's the hook of the current page (not of the next page).

Upon back/forward navigation, Vike reverts the URL. (If the user jumps over several history entries at once, then Vike only reverts one entry.)
