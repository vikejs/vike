
This error means you're using a Vike extension that installs a server middleware via <Link href="/middleware">`+middleware`</Link> while you're using <Link href="/renderPage">`renderPage()`</Link> which <Link href="/renderPage#renderpage-vs-vike-app">doesn't support `+middleware`</Link>.

Use `vike(app)` instead of `renderPage()`, see
- <Link href="/server" />
