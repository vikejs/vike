List of built-in hooks. (You can <Link href="/meta">create your own</Link>.)

See also: <Link href="/settings" />.


## Basics

- <Link href="/data">**`data()`**</Link>: <TextEnv>server (configurable)</TextEnv> Called before the page is rendered, for fetching data.
- <Link href="/guard">**`guard()`**</Link>: <TextEnv>server (configurable)</TextEnv> Protect pages from unprivileged access.
- <Link href="/onHydrationEnd">**`onHydrationEnd()`**</Link>: <TextEnv>client</TextEnv> Called after the page is <Link href="/hydration">hydrated</Link>.
- <Link href="/onPageTransitionStart">**`onPageTransitionStart()`**</Link>: <TextEnv>client</TextEnv> Called upon page navigation, before the new page starts rendering.
- <Link href="/onPageTransitionEnd">**`onPageTransitionEnd()`**</Link>: <TextEnv>client</TextEnv> Called upon page navigation, after the new page has finished rendering.
- <Link href="/onCreatePageContext">**`onCreatePageContext()`**</Link>: <TextEnv>server & client</TextEnv> Called when a <Link href="/pageContext">`pageContext` object</Link> is created.
- <Link href="/onCreateGlobalContext">**`onCreateGlobalContext()`**</Link>: <TextEnv>server & client</TextEnv> Called when the <Link href="/globalContext">`globalContext` object</Link> is created.
- <Link href="/onData">**`onData()`**</Link>: <TextEnv>server & client</TextEnv> Called as soon as <Link href="/pageContext#data">`pageContext.data`</Link> is available.

**Pre-rendering**

- <Link href="/onBeforePrerenderStart">**`onBeforePrerenderStart()`**</Link>: <TextEnv>server</TextEnv> Called for initializing <Link href="/pre-rendering">pre-rendering</Link>.
- <Link href="/onPrerenderStart">**`onPrerenderStart()`**</Link>: <TextEnv>server</TextEnv> Called when <Link href="/pre-rendering">pre-rendering</Link> starts.

**Instrumentation**

- <Link href="/onHookCall">**`onHookCall()`**</Link>: <TextEnv>server & client</TextEnv> Called whenever a hook is invoked. Useful for error tracking and performance monitoring.
- <Link href="/onError">**`onError()`**</Link>: <TextEnv>server</TextEnv> Called when an error occurs on the server.

**`vike-vue`**

- <Link href="/onCreateApp">**`onCreateApp()`**</Link>: <TextEnv>server & client</TextEnv> <Link href="/vike-vue">`vike-vue`</Link> Called after creating Vue's `app` instance.



## Advanced

> Most users don't need to know about these hooks.

- <Link href="/onBeforeRender">**`onBeforeRender()`**</Link>: <TextEnv>server (configurable)</TextEnv> Called before the page is rendered, lower-level and usually for advanced integrations with data fetching tools.
- <Link href="/onRenderHtml">**`onRenderHtml()`**</Link>: <TextEnv>server</TextEnv> Called when a page is rendered to HTML (or to <Link href="/onRenderHtml#non-html-content">non-HTML content</Link>) on the server-side.
- <Link href="/onRenderClient">**`onRenderClient()`**</Link>: <TextEnv>client</TextEnv> Called when a page is rendered on the client-side.
- <Link href="/onBeforeRoute">**`onBeforeRoute()`**</Link>: <TextEnv>server & client</TextEnv> Called before the URL is routed to a page.
- <Link href="/onBeforeRenderClient">**`onBeforeRenderClient()`**</Link>: <TextEnv>client</TextEnv> Called at the beginning of <Link href="/onRenderClient">`onRenderClient()`</Link>.
- <Link href="/onAfterRenderClient">**`onAfterRenderClient()`**</Link>: <TextEnv>client</TextEnv> Called at the end of <Link href="/onRenderClient">`onRenderClient()`</Link>.
- <Link href="/onBeforeRenderHtml">**`onBeforeRenderHtml()`**</Link>: <TextEnv>server</TextEnv> Called at the beginning of <Link href="/onRenderHtml">`onRenderHtml()`</Link>.
- <Link href="/onAfterRenderHtml">**`onAfterRenderHtml()`**</Link>: <TextEnv>server</TextEnv> Called at the end of <Link href="/onRenderHtml">`onRenderHtml()`</Link>.

## Lifecycle

The order in which hooks are called upon rendering a page. (The hook flow.)

> **Data hook environment**
>
> Select the following:
> - `Server-only (default)` if you use `+data.js` or `+onBeforeRender.js`. (They run only on the server.)
> - `Client-only` if you use <Link href="/data#environment">`+data.client.js`</Link> or <Link href="/onBeforeRender#environment">`+onBeforeRender.client.js`</Link>. (They run only on the client.)
> - `Server & client` if you use `+data.shared.js` or `+onBeforeRender.shared.js`. (They run on both the server and the client.)

> <Link href="/routing">Routing</Link> executes the <Link href="/route-function">Route Function</Link> of all your pages.
