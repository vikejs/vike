The `description` setting sets the [SEO description tags](https://moz.com/learn/seo/meta-description).

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  description: 'This website is a Vike demo.'
} satisfies Config
```

> It adds
> [`<meta name="description">`](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Webpage_metadata)
> and
> [`<meta property="og:description">`](https://ogp.me)
> to `<head>`:
>
>
> ```html
> <head>
>   <meta name="description" content="This website is a Vike demo.">
>   <meta property="og:description" content="This website is a Vike demo.">
> </head>
> ```

You can set its value using a <Link href="/pageContext">`pageContext`</Link> function:

```ts
// pages/some-page/+description.ts
// Environment: server, client

import type { Data } from './+data'
import type { PageContext } from 'vike/types'

export function description(pageContext: PageContext<Data>) {
  return pageContext.data.product.description
}
```


## Under the hood

On the server-side, upon rendering the HTML of the first page, the `description` setting adds the `<meta name="description">` and `<meta property="og:description">` tags to the [`<head>` tag](https://developer.mozilla.org/en-US/docs/Learn/HTML/Introduction_to_HTML/The_head_metadata_in_HTML).

On the client-side, upon <Link href="/client-routing">client-side page navigation</Link>, the `description` setting dynamically updates these tags by mutating the DOM.

> While crawlers (e.g. search engine bots) read the description from the HTML, some tools read it from the DOM of the page the user is currently viewing — for example browser extensions for bookmarking and social sharing.
