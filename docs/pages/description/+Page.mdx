The `description` setting sets the [SEO description tags](https://moz.com/learn/seo/meta-description).

```ts
// pages/+config.ts

import type { Config } from 'vike/types'

export default {
  description: 'This website is a Vike demo.'
} satisfies Config
```

> It adds
> [`<meta name="description">`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name#description)
> and
> [`<meta property="og:description">`](https://ogp.me)
> to [`<head>`](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Webpage_metadata):
>
>
> ```html
> <head>
>   <meta name="description" content="This website is a Vike demo.">
>   <meta property="og:description" content="This website is a Vike demo.">
> </head>
> ```

You can set its value using a <Link href="/pageContext">`pageContext`</Link> function:

```ts
// pages/some-page/+description.ts
// Environment: server, client

import type { Data } from './+data'
import type { PageContext } from 'vike/types'

export function description(pageContext: PageContext<Data>) {
  return pageContext.data.product.description
}
```
