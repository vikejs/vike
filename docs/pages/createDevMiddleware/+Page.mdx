Create server middleware for development with <Link href="/glossary#hmr">HMR</Link> and <Link href="/lazy-transpiling">lazy transpiling</Link>.

> You don't need `createDevMiddleware()` if you use <Link href="/server">`+server.js`</Link>. (You also don't need it if you fully <Link href="/pre-rendering">pre-render</Link> your app and therefore don't need a server.)

```ts
import { createDevMiddleware } from 'vike/server'

const {
  devMiddleware, // The development middleware
  viteConfig, // Resolved Vite configuration
  viteServer // Vite's development server
} = await createDevMiddleware({
  root: './path/to/app', // (optional, but recommended)
  viteConfig: {
    // Some Vite configuration (optional)
  }
})
```

> The `createDevMiddleware()` options aren't available if you use <Link href="/serverEntry">`+serverEntry.js`</Link> at development. (Because Vite's development server is created before `+serverEntry.js` is run.) You can use `vite.config.js` or `+config.js` instead.

See <Link href="/renderPage#usage">usage example</Link> for how to use it.

Vite types:
- [InlineConfig](https://vite.dev/guide/api-javascript.html#inlineconfig) types the `viteConfig` option.
- [ResolvedConfig](https://vite.dev/guide/api-javascript.html#resolvedconfig) types the `viteConfig` return value.
- `createDevMiddleware()` wraps [Vite's `createServer()`](https://vite.dev/guide/api-javascript.html#createserver).


## Connect to Web `Request`/`Response`

`devMiddleware` is a [Connect](https://www.npmjs.com/package/connect) middleware: it uses Node.js's `req`/`res`. To use it with a server based on Web Standards (`Request`/`Response`), such as Hono, `Bun.serve()` or `Deno.serve()`, you need a bridge, for example [srvx](https://srvx.h3.dev)'s `fetchNodeHandler()`:

```ts
import { createDevMiddleware } from 'vike/server'
import { fetchNodeHandler } from 'srvx/node'

const { devMiddleware } = await createDevMiddleware()

async function handleDevRequest(request: Request): Promise<Response | undefined> {
  let handled = true
  const response = await fetchNodeHandler(
    (req, res, next) =>
      devMiddleware(req, res, () => {
        handled = false
        next()
      }),
    request
  )
  return handled ? response : undefined
}
```

> Vite wants to move away from Connect, see [vitejs/ecosystem#16](https://github.com/vitejs/ecosystem/issues/16).
