On the server, upon rendering the HTML of the first page, the <code>{props.name}</code> setting adds the {props.children} to the [`<head>` tag](https://developer.mozilla.org/en-US/docs/Learn/HTML/Introduction_to_HTML/The_head_metadata_in_HTML).

On the client, upon <Link href="/client-routing">client-side page navigation</Link>, the <code>{props.name}</code> setting dynamically updates these tags by mutating the DOM.
